| File        | Keterangan                                | Status   |
|-------------|-------------------------------------------|----------|
| `demo.mp4`  | Video demo / preview undangan (opsional)  | Opsional |

> tambahkan elemen berikut di section yang diinginkan:
>
> ```html
> <video src="assets/videos/demo.mp4" controls playsinline></video>
> ```
