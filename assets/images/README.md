# Folder Gambar

Semua gambar di sini sudah tersimpan lokal (situs tidak bergantung pada server eksternal).

| File                  | Dipakai di                          |
|-----------------------|-------------------------------------|
| `logo.png`            | Logo navbar (kiri atas) & favicon   |
| `hero.png`            | Background gambar section Keunggulan |
| `feature-preview.png` | Gambar kecil di section Keunggulan  |
| `builder.png`         | Avatar "Meet The Builder"           |
| `testi-1..4.png`      | Foto avatar testimonial             |
| `pricing-hero.jpg`    | Gambar di section Harga             |
| `payment.png`         | Logo metode pembayaran              |

> Gambar **preview tema** (Floral, Minimalist, dll.) sengaja tetap memuat dari
> CDN resmi invee (`https://sgp1.vultrobjects.com/...`) karena jumlahnya 77 dan
> sudah memakai HTTPS sehingga aman saat di-deploy.

## Tips optimasi (opsional)
Untuk loading lebih ringan, gambar `.png/.jpg` bisa dikonversi ke `.webp`
(mis. via [squoosh.app](https://squoosh.app)) lalu perbarui referensinya.
